## 🔥 Current Research

I'm currently working on an SDN security research project:

> **Adaptive Flow Admission for Low-Rate Flow-Table Overflow Attacks in SDN using Reinforcement Learning**

The goal is to move from reactive attack handling to proactive admission control by using controller-side signals such as flow-table occupancy, Packet-In pressure, and suspicion indicators.

**Tools used:**
`Mininet` `Open vSwitch` `Ryu` `POX` `OpenFlow` `Python` `Pandas` `Matplotlib`
