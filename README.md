## 🔥 Current Research

### Adaptive Flow Admission for Low-Rate Flow-Table Overflow Attacks in SDN using Reinforcement Learning

I am currently working on an SDN security research project that aims to move from reactive attack handling to proactive admission control.

The research focuses on protecting SDN switches from low-rate flow-table overflow attacks by using controller-side signals such as:

- Flow-table occupancy
- Packet-In pressure
- Suspicion indicators
- Admission/rejection decisions
- Controller burden
- Benign traffic impact

**Research Environment:**

`Mininet` `Open vSwitch` `OpenFlow` `POX` `Ryu` `Python` `Pandas` `Matplotlib`

**Research Direction:**

- Build SDN testbed
- Generate normal, flash-crowd, LFTO, and mixed traffic scenarios
- Compare different admission-control policies
- Evaluate flow-table occupancy, Packet-In rate, benign drop rate, attack drop rate, throughput, and latency
- Use reinforcement learning to support adaptive admission decisions
